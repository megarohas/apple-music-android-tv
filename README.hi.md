## यह क्या है?

**Android TV / Google TV के लिए Apple Music का कोई आधिकारिक ऐप नहीं है**। Apple का Android फ़ोन वाला ऐप साइडलोड किया जा सकता है, लेकिन वह टच स्क्रीन के लिए बना है और रिमोट से उसे चलाना सिरदर्द है। फ़ोन से कास्ट करना काम करता है, लेकिन तब आपका फ़ोन ही रिमोट बन जाता है।

**AMTV** आपके TV को एक असली Apple Music ऐप देता है:

- आप अपने Apple ID से **सिर्फ़ एक बार** साइन इन करते हैं, Apple के अपने साइन इन पेज पर;
- रिमोट के ऐरो बटन से **होम, ब्राउज़ करें, रेडियो, लाइब्रेरी और खोजें** में घूमते हैं;
- OK दबाते हैं और संगीत बजने लगता है, और स्क्रीन पर शांत, फ़ुल-स्क्रीन **अभी चल रहा है** व्यू खुलता है।

यह मुफ़्त और ओपन सोर्स है, और इसमें **कोई हैक नहीं** है: अंदर **Apple का आधिकारिक वेब प्लेयर** ([music.apple.com](https://music.apple.com)) चलता है, और AMTV उसके ऊपर बस TV के लिए आसान इंटरफ़ेस लगाता है। प्लेबैक, DRM और आपका खाता Apple के पास ही रहते हैं।

> आपके पास **Apple Music सब्सक्रिप्शन** होना चाहिए। AMTV का Apple से कोई संबंध नहीं है और Apple ने इसका समर्थन नहीं किया है।

- 🎛️ **रिमोट के लिए बना** — ऐरो बटन कार्ड के बीच ले जाते हैं, OK चलाता या खोलता है, वापस जाएँ बटन पिछली स्क्रीन पर ले जाता है। हर पंक्ति में फ़ोकस याद रखता है कि आप कहाँ थे।
- 🏠 **होम** — आपके लिए निजी सुझाव: *Made for You* प्लेलिस्ट, हाल ही में चलाए गए, आपके लिए स्टेशन, नई रिलीज़।
- 🧭 **ब्राउज़ करें और रेडियो** — Apple के संपादकीय संग्रह, चार्ट, लाइव रेडियो (Apple Music 1, Hits, Country…) और रेडियो शो।

- 🔍 **खोजें** — कलाकार, गीत, ऐल्बम, प्लेलिस्ट और स्टेशन, खोज हिस्ट्री के साथ।

- 🎵 **अभी चल रहा है** — बड़ा कवर, ट्रैक के बीच स्मूद ट्रांज़िशन, कवर के रंगों से रंगा बैकग्राउंड; कंट्रोल अपने-आप छिप जाते हैं, उनके छिपे रहने पर **←/→ ट्रैक बदलते हैं**, और स्मूद नॉब से गीत में आगे-पीछे जा सकते हैं। लंबे शीर्षक स्क्रॉल होते हैं; कवर, शीर्षक, कलाकार और घड़ी धीरे-धीरे एक साथ तैरते हैं, ताकि स्क्रीन पर किसी चीज़ का निशान न पड़ जाए। संगीत बजते समय TV का स्क्रीनसेवर नहीं आता, और तब “अभी चल रहा है” टैब पर छोटे बार हिलते रहते हैं।
- ⭐ **पसंदीदा** — प्लेयर में स्टार (Apple Music के ⭐ जैसा ही)।

## इंस्टॉल करें

### क्या चाहिए

- **Android 10 या नए वर्शन** वाला **Android TV / Google TV** डिवाइस (TV बॉक्स, स्टिक, Android TV / Google TV वाले TV)।
- **Apple Music सब्सक्रिप्शन** और आपका **Apple ID**।
- 5 मिनट।

### तरीक़ा 1 — मुफ़्त “Downloader” ऐप से (सबसे आसान, कंप्यूटर की ज़रूरत नहीं)

1. TV पर **Google Play** खोलें और **Downloader** (AFTVnews का) इंस्टॉल करें।
2. उसे ऐप इंस्टॉल करने की अनुमति दें: **सेटिंग → ऐप्लिकेशन → सुरक्षा और पाबंदियां → अज्ञात स्रोत → Downloader → चालू**
   *(अलग-अलग TV पर यह रास्ता थोड़ा अलग होता है; सेटिंग में “अज्ञात स्रोत” खोजें)*।
3. **Downloader** खोलें, यह पता टाइप करें और **Go** दबाएँ:
   ```
   https://github.com/megarohas/apple-music-android-tv/releases/latest/download/amtv.apk
   ```
4. डाउनलोड पूरा होने पर **इंस्टॉल करें** दबाएँ, फिर **खोलें**।

### तरीक़ा 2 — फ़ोन या कंप्यूटर से फ़ाइल भेजें

1. [`amtv.apk`](https://github.com/megarohas/apple-music-android-tv/releases/latest/download/amtv.apk) डाउनलोड करें।
2. उसे **Send Files to TV**, **LocalSend** जैसे किसी ऐप से या USB स्टिक से TV पर भेजें।
3. TV पर किसी फ़ाइल मैनेजर से उसे खोलें और **इंस्टॉल करें** दबाएँ (पूछे जाने पर उस फ़ाइल मैनेजर को “अज्ञात स्रोत” की अनुमति दें)।

### तरीक़ा 3 — ADB (तकनीक के शौक़ीनों के लिए)

```bash
adb connect <TV-का-IP>:5555
adb install amtv.apk
```

### पहली बार खोलने पर

1. ऐप्स की पंक्ति से **AMTV** खोलें (म्यूज़िक नोट वाली लाल टाइल)।
2. **साइन इन करें** दबाएँ — Apple का अपना साइन इन पेज खुलता है, जो रिमोट के लिए ढाला गया है: **↑ / ↓** से फ़ील्ड या बटन चुनें (लाल फ़्रेम), फ़ील्ड पर **OK** दबाने से ऑन-स्क्रीन कीबोर्ड खुलता है, बटन पर **OK** दबाने से वह बटन दब जाता है। अपना Apple ID टाइप करें → जारी रखें → पासवर्ड → साइन इन करें। टू-फ़ैक्टर कोड हमेशा की तरह आपके iPhone / Mac पर आते हैं।
   > टिप: फ़ोन पर **Google TV** ऐप TV के लिए कीबोर्ड का काम करता है — आप पासवर्ड मैनेजर से अपना पासवर्ड पेस्ट कर सकते हैं।
3. हो गया — AMTV TV इंटरफ़ेस पर आ जाता है। आप साइन इन रहते हैं; अगली बार ऐप सीधे होम पर खुलता है।

> आपका पासवर्ड **सिर्फ़ Apple के पेज पर** (`idmsa.apple.com`) टाइप होता है। AMTV उसे न कभी देखता है, न सेव करता है।

## रिमोट से इस्तेमाल

| बटन | क्या करता है |
|---|---|
| **← ↑ → ↓** | कार्ड, पंक्तियों और ऊपर वाली पट्टी के बीच घूमें। किसी टैब पर पहुँचते ही वह खुल जाता है। |
| **पंक्ति के अंत में → / शुरुआत में ←** | अगले / पिछले टैब पर जाएँ (होम से **←** सीधे “अभी चल रहा है” पर ले जाता है)। |
| **OK** | गीत या स्टेशन चलाएँ, ऐल्बम / प्लेलिस्ट / कलाकार खोलें। |
| **OK दबाकर रखें** | मेनू: चलाएँ, शफ़ल करें, अगला चलाएँ, आखिरी में चलाएँ, लाइब्रेरी में जोड़ें, स्टेशन बनाएँ। |
| **वापस जाएँ** | पिछला पेज → होम → ऐप से बाहर (संगीत रुक जाता है)। |
| **प्ले/पॉज़, अगला, पिछला** (अगर रिमोट में हों) | ऐप में कहीं से भी संगीत कंट्रोल करें। |

**अभी चल रहा है** में:

| बटन | क्या करता है |
|---|---|
| कोई भी बटन | कंट्रोल दिखाता है (कुछ सेकंड बाद वे छिप जाते हैं) |
| कंट्रोल छिपे होने पर **← / →** | पिछला / अगला ट्रैक |
| **↓** से प्रोग्रेस बार पर, फिर **← / →** | हर बार दबाने पर 10 सेकंड आगे-पीछे (रुकने पर एक ही स्मूद जंप) |
| ⭐ | पसंदीदा में जोड़ें / पसंदीदा से हटाएँ |
| बोल वाला बटन | गीत के बोल चालू / बंद |

## वॉइस असिस्टेंट और ऑटोमेशन

AMTV आसान कमांड को Android इंटेंट के रूप में स्वीकार करता है, इसलिए वॉइस रिमोट, Tasker जैसे टूल या कोई स्क्रिप्ट इसे चला सकते हैं:

```bash
# स्टेशन / प्लेलिस्ट / ऐल्बम चलाएँ (ज़रूरत हो तो ऐप खोलता है, संगीत शुरू होने पर प्लेयर दिखाता है)
adb shell am start -n com.megarohas.amtv/.MainActivity --es play ra.978194965      # Apple Music 1
adb shell am start -n com.megarohas.amtv/.MainActivity --es play pl.<प्लेलिस्ट-id>

# प्लेयर कंट्रोल करें
adb shell am start -n com.megarohas.amtv/.MainActivity --es cmd next        # next | prev | pause | play | toggle
adb shell am start -n com.megarohas.amtv/.MainActivity --es cmd favorite    # ⭐ अभी चल रहा गीत जोड़ें
adb shell am start -n com.megarohas.amtv/.MainActivity --es cmd unfavorite  # उसे हटाएँ (अगर वह पसंदीदा में नहीं है, तो कुछ नहीं होता)
```

ID वही हैं जो Apple Music के लिंक में होते हैं (`music.apple.com/…/playlist/…/pl.xxxx`, स्टेशन `ra.…`, ऐल्बम के ID नंबर होते हैं)। वॉइस रिमोट [megarohas_tv_voice](https://github.com/megarohas/megarohas_tv_voice) ठीक यही इस्तेमाल करता है: *“Remote, play music”* कहने पर TV बॉक्स जाग जाता है, AMTV खुलता है और आपका स्टेशन शुरू हो जाता है।

## सवाल और जवाब

<details><summary><b>क्या Android TV / Google TV के लिए Apple Music का कोई आधिकारिक ऐप है?</b></summary>

नहीं (2026 तक)। Apple, Android फ़ोन और कुछ स्मार्ट TV (Samsung, LG) के लिए Apple Music देता है, लेकिन Android TV / Google TV बॉक्स के लिए नहीं। AMTV यह कमी Apple के अपने वेब प्लेयर से पूरी करता है।
</details>

<details><summary><b>क्या यह क़ानूनी है? क्या यह DRM तोड़ता है?</b></summary>

AMTV DRM को बायपास **नहीं** करता और टोकन भी नहीं निकालता। संगीत Apple के आधिकारिक वेब प्लेयर से, TV में पहले से मौजूद Widevine के साथ चलता है — बिल्कुल वैसे ही जैसे कंप्यूटर के ब्राउज़र में music.apple.com पर। आपको अपना पेड सब्सक्रिप्शन चाहिए। AMTV एक स्वतंत्र, अनौपचारिक प्रोजेक्ट है।
</details>

<details><summary><b>क्या यह मेरे TV बॉक्स / Fire TV पर चलेगा?</b></summary>

इसे **Xiaomi TV Box S (दूसरी पीढ़ी), Google TV, Android 14** पर टेस्ट किया गया है। यह Android 10+ और Widevine वाले किसी भी Android TV / Google TV डिवाइस पर चलना चाहिए (यानी लगभग सभी सर्टिफ़ाइड डिवाइस: Chromecast with Google TV, NVIDIA Shield, Mi Box, Onn, Google TV वाले TV)। लोगों ने बताया है कि यह Changhong TV (Android 11) और Sony Bravia (Android TV 12) पर भी चलता है। Fire TV पर टेस्ट नहीं हुआ है — आपकी रिपोर्ट का स्वागत है।
</details>

<details><summary><b>Lossless, Dolby Atmos, म्यूज़िक वीडियो?</b></summary>

AMTV वही चलाता है जो Apple का वेब प्लेयर चलाता है: हाई-क्वालिटी AAC। Lossless और Dolby Atmos वेब पर उपलब्ध नहीं हैं। म्यूज़िक वीडियो अभी सपोर्ट नहीं होते।
</details>

<details><summary><b>पहली बार खुलने में ~10 सेकंड क्यों लगते हैं?</b></summary>

ऐप Apple का वेब प्लेयर लोड करता है और आपका साइन इन वापस लाता है; स्टार्ट स्क्रीन दिखाती है कि अभी क्या हो रहा है। स्टेशन शुरू होने में कुछ सेकंड लगते हैं, क्योंकि चलाने से पहले Apple का प्लेयर स्टेशन के ट्रैक, प्लेबैक लाइसेंस और ऑडियो का पहला हिस्सा लाता है। इसके बाद नेविगेशन कैश हो जाता है और तेज़ चलता है।
</details>

<details><summary><b>क्या ऐप से बाहर जाने पर संगीत चलता रहता है?</b></summary>

ऐप से बाहर जाने पर (होम बटन, कोई दूसरा ऐप) संगीत रुक जाता है, लेकिन TV के स्क्रीनसेवर के नीचे चलता रहता है।
</details>

<details><summary><b>कॉन्टेंट किसी दूसरे देश का है</b></summary>

Apple Music आपके Apple ID के देश का कैटलॉग दिखाता है। साइन इन से पहले वेबसाइट आपके IP पते से देश का अंदाज़ा लगा सकती है।
</details>

| हर बार “साइन इन ज़रूरी है” | देखें कि TV की तारीख़ और समय सही हैं; सेटिंग्स → वेबसाइट मोड से फिर से साइन इन करें। |
| आवाज़ नहीं, या “प्लेबैक शुरू नहीं हो सका” | आपके डिवाइस में Widevine होना चाहिए (Google से सर्टिफ़ाइड सभी TV में होता है)। music.apple.com पर देखें कि आपका सब्सक्रिप्शन चालू है। |

| अपडेट के बाद कुछ गड़बड़ दिखता है | सेटिंग्स → **डेटा रीफ़्रेश करें**, या Android की सेटिंग में ऐप का स्टोरेज साफ़ करें (फिर से साइन इन करना होगा)। |

## यह कैसे काम करता है

```
┌──────────────── AMTV (Android app) ────────────────┐
│  WebView ── music.apple.com (Apple's web player)    │
│    │          ├── MusicKit JS: your signed-in session│
│    │          └── <audio> + Widevine: playback       │
│    └── TV interface (HTML/CSS/JS in a shadow DOM)    │
│           data  ← MusicKit API (amp-api)             │
│           play  → MusicKit setQueue / play           │
│  Remote keys ─► MainActivity ─► the TV interface     │
│  Intents (--es play / --es cmd) ─► the player        │
└─────────────────────────────────────────────────────┘
```

- **DRM के साथ कोई चालाकी नहीं, टोकन निकालना नहीं।** इंटरफ़ेस पेज के अपने, पहले से साइन इन किए हुए MusicKit सेशन के ज़रिए Apple के API से डेटा माँगता है और MusicKit से ही प्लेबैक शुरू करता है, जैसे वेबसाइट करती है।
- **Apple का अपना पेज लोड रहता है, लेकिन छिपा रहता है** (`display: none`) — प्लेयर उसी के पास है। AMTV उसे बिना एनिमेटेड आर्टवर्क वाले पेज पर रखता है और वे रिक्वेस्ट ठुकरा देता है जो वह पेज सिर्फ़ अपने लिए करता (मोशन-आर्टवर्क वीडियो, उसके अपने थंबनेल, एनालिटिक्स): धीमे बॉक्स पर इसी से स्टेशन 20 सेकंड की जगह 4 सेकंड में शुरू होने लगा।
- **कमज़ोर GPU के लिए बना** — न blur फ़िल्टर, न अंतहीन एनिमेशन; “अभी चल रहा है” का बैकग्राउंड 64×36 का धुंधला canvas है, जो हर गीत पर एक बार बनता है और फैला दिया जाता है; गीत के बोल हर फ़्रेम वाले लूप से नहीं, बल्कि अगले शब्द पर सेट टाइमर से आगे बढ़ते हैं; तैरना, स्क्रॉल होता कैप्शन और प्रोग्रेस बार एक ही टिक (सेकंड में 10 बार) पर चलते हैं और रोकी हुई (paused) एनिमेशन के ज़रिए हिलते हैं, इसलिए कोई भी कदम पेज की लेयर दोबारा नहीं बनवाता; “अभी चल रहा है” टैब के बार सेकंड में कुछ ही बार हिलते हैं, सिर्फ़ तब जब संगीत चल रहा हो और ऊपर वाली पट्टी स्क्रीन पर हो, और एक मिनट तक कोई बटन न दबाने पर रुक जाते हैं; Apple के छिपे पेज को कोई एनिमेशन चलाने ही नहीं दिया जाता।
- **सटीक प्ले टाइम** — MusicKit समय पूरे सेकंड में बताता है; प्रोग्रेस बार और घड़ी प्लेयर के सटीक समय के हिसाब से चलते हैं, इसलिए कभी पीछे नहीं जाते।
- **रिमोट से नेविगेशन** — एक छोटा फ़ोकस इंजन: फ़ोकस हो सकने वाले आइटम की पंक्तियाँ, हर पंक्ति में पिछली जगह की याद, `transform` से खिसकने वाली शेल्फ़, किनारे से टैब बदलना, और वेबसाइट मोड के लिए माउस पॉइंटर।

## सोर्स से बिल्ड करें

Gradle नहीं — Makefile सीधे Android SDK के टूल चलाता है; बिल्ड में कुछ ही सेकंड लगते हैं।

ज़रूरतें: **Android SDK** (build-tools 36.0.0, प्लेटफ़ॉर्म `android-36`), **JDK 17 या नया**, `make`, `adb`।

```bash
git clone https://github.com/megarohas/apple-music-android-tv.git
cd apple-music-android-tv
make                                   # → build/amtv.apk (आपकी debug key से साइन किया हुआ)
make install TV=192.168.1.50:5555      # adb से जुड़ा TV बॉक्स; या `TV = …` को local.mk में लिखें
make start

make dev-install && make dev-start    # टेस्टिंग के लिए बगल में एक अलग “AMTV Dev” ऐप (अपना साइन इन और डेटा)
```

पाथ बदले जा सकते हैं: `make SDK=/path/to/sdk BT=$SDK/build-tools/36.0.0`।

दोबारा इंस्टॉल किए बिना असली TV पर डेवलप करें:

```bash
make devtools                                  # WebView के DevTools को localhost:9222 पर फ़ॉरवर्ड करता है
node tools/cdp.mjs run res/raw/tv_i18n.js res/raw/tv_core.js res/raw/tv_screens.js res/raw/tv_player.js
node tools/cdp.mjs eval '__tv.boot()'          # इंटरफ़ेस हॉट-रीलोड हो जाता है
node tools/cdp.mjs shot screen.png             # या chrome://inspect में जाँचें
```

कस्टम ब्रांडिंग (आपके अपने आइकन और फ़ॉन्ट) `res/raw/brand.js` और `assets/fonts/` में जाती है — उस फ़ाइल की टिप्पणियाँ देखें।

### नई भाषा जोड़ना

1. `res/raw/tv_i18n.js` — अंग्रेज़ी टेबल कॉपी करें, वैल्यू का अनुवाद करें और भाषा को `LANGS` में जोड़ें (उसका कोड और उसका अपना नाम)।
2. `res/values-<code>/strings.xml` — स्टार्ट स्क्रीन की सात पंक्तियाँ।
3. `res/raw/signin.js` — Apple के साइन इन पेज पर रिमोट के लिए एक पंक्ति का संकेत।
4. चाहें तो `README.<code>.md` भी, जिसका लिंक हर README के ऊपर भाषाओं वाली पंक्ति में हो।

स्ट्रिंग की लंबाई लगभग अंग्रेज़ी जितनी रखें: ऊपर वाली पट्टी और प्लेयर में जगह कम है। फिर `make` चलाएँ और TV पर हर टैब देखें।
